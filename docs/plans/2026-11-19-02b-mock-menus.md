# Milestone 2b: mock menus, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a menu for every restaurant in the 220-restaurant file, served from this repository like the list:
- `mock-api/v1/menus/{id}.json`, one per distinct id: 218 files;
- deterministic, curated per concept and Cape Town-flavoured, with spec §5.9's rates and eleven deliberate edge cases for milestone 3's validation;
- `restaurants.json` and `restaurants-10k.json` stay byte-identical. Stress-only restaurants have no menu, so the API answers 404 for them.

**Architecture:**
- **`:tools:datagen` grows three files.** `Courses.kt` holds each concept's courses and dishes, `MenuGenerator.kt` builds and writes the menus, and `MenuEdgeCases.kt` breaks eleven of them on purpose. `./gradlew :tools:datagen:run` writes the menus after the two datasets and deletes any menu file whose restaurant has gone.
- **The restaurants don't change.** `Generator.generate` hands out each restaurant's concept and photo key alongside its record, without drawing anything more. Menu *i* draws from its own `Random((SEED * 31 + i) xor STREAM)`, so it depends only on the seed, *i* and the concept.
- **Exact JSON,** as in milestone 2: `JsonObject` builders, `JsonWriter.pretty` with two-space indents, and edge cases applied to the JSON, so a missing key, a `null` and a string price are exactly what milestone 3's tests need.
- **The golden test** covers every menu file and the set of file names. Its Gradle input, `mock-api/v1/`, already covers `menus/`.

**Tech stack:** Kotlin 2.3.21 on the JVM (JDK 17 API), kotlinx.serialization JSON 1.11.0, JUnit 4.13.2 with `TemporaryFolder`. No new library.

**Spec:** `docs/specs/2026-11-18-restaurant-discovery-design.md`, §5.9 (menus), §5.1 and §5.2, and §11 (AC-24, which this milestone's data serves). **Roadmap:** `docs/plans/2026-11-18-00-roadmap.md`, milestone 2b.

**Branch:** `feature/mock-menus`, cut from `dev`, with this plan as its first commit. It ends in one pull request into `dev`. There's no release: the menus reach `master` with the next one. Run every command from the repository root.

  - **The deny list** gains sixteen food and drink brands, and the test covers every course name, dish, description and option.
  - **`.gitattributes`.** `mock-api/v1/*.json` doesn't match files in `menus/`, because `*` stops at `/`: `git check-attr` reported `unspecified`. A second line marks the menus as generated.
- **A probe that didn't run:** the spike's first golden-test probe edited the wrong line, so nothing changed and the test passed. `git diff --stat` showed the empty edit. Every break-it step below shows its diff before running the test.

```kotlin
package com.effekt3r.mrd.tools.datagen

import java.time.DayOfWeek
import java.time.DayOfWeek.FRIDAY
import java.time.DayOfWeek.SATURDAY
import java.time.DayOfWeek.SUNDAY
import kotlin.random.Random
import kotlinx.serialization.json.JsonObject

/**
 * Generates the restaurants. Restaurant i draws from its own Random(SEED * 31 + i), so it depends only on the seed,
 * its index and the names before it: generating twice gives the same restaurants, and the first 220 of 10,000 are
 * exactly the 220 of the standard dataset. kotlin.random only promises the same sequence within one Kotlin version,
 * so a Kotlin upgrade may change the data. GoldenFilesTest then fails, and regenerating is the fix.
 */
internal object Generator {

    const val SEED = 20_261_118L

    /** Friday 19:00 in Cape Town: the moment `is_open` describes, like a server snapshot that's never refreshed. */
    val SNAPSHOT_WEEK_MINUTE = FRIDAY.ordinal * MINUTES_PER_DAY + at(19)

    // Spec §5.2's rates, in percent, each drawn per restaurant.
    private const val NO_RATING_PERCENT = 6
    private const val NO_FEE_PERCENT = 4
    private const val FREE_DELIVERY_PERCENT = 15
    private const val NO_ETA_PERCENT = 4
    private const val NO_IMAGE_PERCENT = 6

    // 5% have no hours: 4% leave the key out and 1% send [].
    private const val NO_HOURS_PERCENT = 5
    private const val EMPTY_HOURS_PERCENT = 1

    // Without hours, `is_open` is all there is.
    private const val OPEN_WITHOUT_HOURS_PERCENT = 70

    fun restaurants(count: Int, pool: ImagePool): List<JsonObject> = generate(count, pool).map { it.record }

    /** The restaurants with what their menus are made from. Generating them draws nothing more than [restaurants]. */
    fun generate(count: Int, pool: ImagePool): List<GeneratedRestaurant> {
        val names = NameBook(uniqueCount = Dataset.STANDARD.size)
        return List(count) { index -> restaurant(index, names, pool) }
    }

    fun idFor(index: Int) = "r-${1001 + index}"

    private fun restaurant(index: Int, names: NameBook, pool: ImagePool): GeneratedRestaurant {
        if (index == 0) return capeTownGrill(pool)
        val random = Random(SEED * 31 + index)

        // Edge cases keep every field, so each one has only the defect EdgeCases gives it.
        val complete = index in EdgeCases.indexes
        fun missing(percent: Int) = !complete && random.nextInt(100) < percent

        val pinned = EdgeCases.pinnedNames[index]
        val concept = pinned?.let { Concepts.named(it.conceptKey) } ?: Concepts.pick(random)
        val name = pinned?.name ?: names.next(index, concept, random)
        val menu = concept.menus.random(random)
        val rating = if (missing(NO_RATING_PERCENT)) null else (32..49).random(random) / 10.0
        // One draw sets the fee, so free delivery is 15% of all restaurants, not of those with a fee.
        val feeDraw = random.nextInt(100)
        val deliveryFeeCents = when {
            feeDraw < NO_FEE_PERCENT && !complete -> null
            feeDraw >= 100 - FREE_DELIVERY_PERCENT -> 0
            else -> concept.feesCents.random(random)
        }
        val etaMinutes = if (missing(NO_ETA_PERCENT)) null else concept.etaMinutes.random(random)
        val imageUrl = if (missing(NO_IMAGE_PERCENT)) null else pool.pick(menu.imageKey, random)
        val openingHours = when {
            !missing(NO_HOURS_PERCENT) -> Hours.generate(concept.hours.random(random), random)
            random.nextInt(NO_HOURS_PERCENT) < EMPTY_HOURS_PERCENT -> emptyList()
            else -> null
        }
        val isOpen = if (openingHours.isNullOrEmpty()) {
            random.nextInt(100) < OPEN_WITHOUT_HOURS_PERCENT
        } else {
            openingHours.isOpenAt(SNAPSHOT_WEEK_MINUTE)
        }
        val restaurant = Restaurant(
            idFor(index), name, menu.cuisines, rating, deliveryFeeCents, etaMinutes, isOpen, imageUrl, openingHours
        )
        return GeneratedRestaurant(EdgeCases.apply(index, restaurant.toJson()), concept, menu.imageKey)
    }

    /** r-1001 is the brief's example, which the app's placeholder already shows. */
    private fun capeTownGrill(pool: ImagePool): GeneratedRestaurant {
        val hours = DayOfWeek.entries.map { day ->
            when (day) {
                FRIDAY, SATURDAY -> OpeningHours(day, at(11), at(2))
                SUNDAY -> OpeningHours(day, at(11), at(21))
                else -> OpeningHours(day, at(11), at(22))
            }
        }
        val restaurant = Restaurant(
            id = idFor(0),
            name = "Cape Town Grill",
            cuisines = listOf("Steakhouse", "Grill"),
            rating = 4.6,
            deliveryFeeCents = 1500,
            etaMinutes = 32,
            isOpen = hours.isOpenAt(SNAPSHOT_WEEK_MINUTE),
            imageUrl = pool.first("beef"),
            openingHours = hours
        )
        return GeneratedRestaurant(restaurant.toJson(), Concepts.named("steakhouse"), photoKey = "beef")
    }
}

/**
 * A generated restaurant: its [record] as the API sends it, edge cases included, and what its menu is made from. The
 * [concept] picks the menu's courses and [photoKey] its dishes' photos; neither is sent.
 */
internal class GeneratedRestaurant(val record: JsonObject, val concept: Concept, val photoKey: String)
```

package com.effekt3r.mrd.tools.datagen

import java.io.File
import kotlin.random.Random
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.addJsonObject
import kotlinx.serialization.json.buildJsonObject
import kotlinx.serialization.json.jsonPrimitive
import kotlinx.serialization.json.put
import kotlinx.serialization.json.putJsonArray

/**
 * Generates the menus: one per distinct restaurant id in the 220-restaurant file, from that id's first record, written
 * to mock-api/v1/menus/{id}.json. Stress-only restaurants have none, so the API answers 404 for them (spec §5.9).
 * Not to be confused with [Concept.menus], the cuisine lists a restaurant draws from.
 */
internal object MenuGenerator {

    const val DIRECTORY = "mock-api/v1/menus"

    /**
     * Menu i draws from its own Random, its restaurant's seed mixed with this constant ("menumenu" in ASCII). It
     * depends only on the seed, its restaurant's index and concept, and the restaurants' draws don't change.
     */
    private const val STREAM = 0x6D65_6E75_6D65_6E75L

    // Spec §5.9's rates, in percent, each drawn per item.
    private const val SOLD_OUT_PERCENT = 8
    private const val NO_DESCRIPTION_PERCENT = 25
    private const val OPTIONS_PERCENT = 30

    // Drinks have no photos, so dishes have one 65% of the time: about half of all items.
    private const val PHOTO_PERCENT = 65

    // Some options are free; the rest cost R5 to R35.
    private const val FREE_OPTION_PERCENT = 20
    private val OPTION_PRICES = (500..3_500 step 500).toList()

    /** Every menu by restaurant id, in restaurant order. */
    fun menus(pool: ImagePool): Map<String, JsonObject> {
        val menus = linkedMapOf<String, JsonObject>()
        Generator.generate(Dataset.STANDARD.size, pool).forEachIndexed { index, restaurant ->
            val id = restaurant.record["id"]?.jsonPrimitive?.content ?: return@forEachIndexed
            if (id !in menus) {
                menus[id] = MenuEdgeCases.apply(index, menu(index, id, restaurant.concept, restaurant.photoKey, pool))
            }
        }
        return menus
    }

    /** Every menu file's text by file name, `{id}.json`. */
    fun files(pool: ImagePool): Map<String, String> =
        menus(pool).entries.associate { (id, menu) -> "$id.json" to JsonWriter.pretty(menu) }

    /**
     * Writes [files] into [directory] and deletes every other `.json` file there: a menu whose restaurant has gone.
     * Returns the names it deleted.
     */
    fun write(directory: File, files: Map<String, String>): List<String> {
        directory.mkdirs()
        files.forEach { (name, text) -> File(directory, name).writeText(text) }
        val stale = directory.listFiles().orEmpty().filter { it.name.endsWith(".json") && it.name !in files }
        stale.forEach { check(it.delete()) { "Couldn't delete $it" } }
        return stale.map { it.name }.sorted()
    }

    /**
     * One restaurant's menu: its concept's courses in order, each listing 4 to 8 of its dishes in menu order. Ids
     * carry the restaurant's number: category `c-1001-1`, item `i-1001-101` (category 1, item 1) and option
     * `o-1001-101-1`. A restaurant prices either in round fives (R85) or just under (R89).
     */
    fun menu(index: Int, restaurantId: String, concept: Concept, photoKey: String, pool: ImagePool): JsonObject {
        val random = Random((Generator.SEED * 31 + index) xor STREAM)
        val number = restaurantId.removePrefix("r-")
        val endsInNine = random.nextBoolean()

        fun item(course: Course, dish: Dish, code: String) = buildJsonObject {
            put("id", "i-$code")
            put("name", dish.name)
            put("price_cents", price(course.rands, endsInNine, random))
            put("available", random.nextInt(100) >= SOLD_OUT_PERCENT)
            if (random.nextInt(100) >= NO_DESCRIPTION_PERCENT) put("description", dish.description)
            val photos = when (course.photos) {
                Photos.RESTAURANT -> photoKey
                Photos.DESSERT -> "dessert"
                Photos.NONE -> null
            }
            if (photos != null && random.nextInt(100) < PHOTO_PERCENT) put("image_url", pool.pick(photos, random))
            if (random.nextInt(100) < OPTIONS_PERCENT) {
                val names = course.options.shuffled(random).take((1..3).random(random))
                putJsonArray("options") {
                    names.forEachIndexed { option, name ->
                        addJsonObject {
                            put("id", "o-$code-${option + 1}")
                            put("name", name)
                            put("price_cents", optionPrice(random))
                        }
                    }
                }
            }
        }

        return buildJsonObject {
            put("restaurant_id", restaurantId)
            putJsonArray("categories") {
                Courses.of(concept).forEachIndexed { position, course ->
                    val category = position + 1
                    addJsonObject {
                        put("id", "c-$number-$category")
                        put("name", course.name)
                        putJsonArray("items") {
                            val count = (4..minOf(8, course.dishes.size)).random(random)
                            val dishes = course.dishes.indices.shuffled(random).take(count).sorted()
                            dishes.forEachIndexed { item, dish ->
                                add(item(course, course.dishes[dish], "$number-${category * 100 + item + 1}"))
                            }
                        }
                    }
                }
            }
        }
    }

    /** A price in [rands], in cents: a multiple of R5, or a rand amount ending in 9 when [endsInNine]. */
    fun price(rands: IntRange, endsInNine: Boolean, random: Random): Int {
        val prices = if (endsInNine) rands.filter { it % 10 == 9 } else rands.filter { it % 5 == 0 }
        return prices.random(random) * 100
    }

    private fun optionPrice(random: Random) =
        if (random.nextInt(100) < FREE_OPTION_PERCENT) 0 else OPTION_PRICES.random(random)
}

package com.effekt3r.mrd.tools.datagen

import kotlinx.serialization.json.JsonArray
import kotlinx.serialization.json.JsonElement
import kotlinx.serialization.json.JsonNull
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.JsonPrimitive

import kotlinx.serialization.json.jsonObject
import kotlinx.serialization.json.jsonPrimitive

/**
 * Deliberately broken menus, at fixed restaurant indexes below 220 that end in 5, so none is a restaurant edge case.
 * Each has exactly one problem, for milestone 3's validation tests (spec §5.9). mock-api/README.md lists them.
 */
internal object MenuEdgeCases {

    // The first item of the first category is dropped.
    const val ITEM_WITHOUT_PRICE = 5
    const val NEGATIVE_PRICE = 15
    const val ITEM_WITHOUT_NAME = 25
    const val PRICE_AS_STRING = 35

    // A category is dropped, or hidden because none of its items survives.
    const val CATEGORY_WITHOUT_NAME = 45
    const val CATEGORY_ALL_INVALID = 55

    // The item is kept without the bad part.
    const val NEGATIVE_OPTION_PRICE = 65
    const val HTTP_IMAGE = 75

    // The whole menu.
    const val WRONG_RESTAURANT_ID = 85
    const val NO_CATEGORIES = 95
    const val DUPLICATE_ITEM_ID = 105

    val indexes = setOf(
        ITEM_WITHOUT_PRICE, NEGATIVE_PRICE, ITEM_WITHOUT_NAME, PRICE_AS_STRING, CATEGORY_WITHOUT_NAME,
        CATEGORY_ALL_INVALID, NEGATIVE_OPTION_PRICE, HTTP_IMAGE, WRONG_RESTAURANT_ID, NO_CATEGORIES, DUPLICATE_ITEM_ID
    )

    fun apply(index: Int, menu: JsonObject): JsonObject = when (index) {
        ITEM_WITHOUT_PRICE -> menu.editFirstItem { it.withField("price_cents", null) }
        NEGATIVE_PRICE -> menu.editFirstItem { it.withField("price_cents", JsonPrimitive(-500)) }
        ITEM_WITHOUT_NAME -> menu.editFirstItem { it.withField("name", null) }
        PRICE_AS_STRING -> menu.editFirstItem { it.withField("price_cents", JsonPrimitive(it.text("price_cents"))) }
        CATEGORY_WITHOUT_NAME -> menu.editCategory(0) { it.withField("name", null) }
        CATEGORY_ALL_INVALID -> menu.editCategory(1) { category ->
            category.withField("items", JsonArray(category.items().map { it.withField("price_cents", JsonNull) }))
        }
        NEGATIVE_OPTION_PRICE -> menu.editFirstItem({ "options" in it }) { item ->
            val options = item.getValue("options").jsonArray.map { it.jsonObject }
            val negative = options.last().withField("price_cents", JsonPrimitive(-500))
            item.withField("options", JsonArray(options.dropLast(1) + negative))
        }
        HTTP_IMAGE -> menu.editFirstItem({ "image_url" in it }) {
            it.withField("image_url", JsonPrimitive(it.text("image_url").replace("https:", "http:")))
        }
        WRONG_RESTAURANT_ID -> menu.withField("restaurant_id", JsonPrimitive(Generator.idFor(index + 1)))
        NO_CATEGORIES -> menu.withField("categories", JsonArray(emptyList()))
        DUPLICATE_ITEM_ID -> menu.editCategory(0) { category ->
            val items = category.items()
            val repeated = items[1].withField("id", items[0].getValue("id"))
            category.withField("items", JsonArray(listOf(items[0], repeated) + items.drop(2)))
        }
        else -> menu
    }

    /** This object with [key] set to [value] in its place, or left out when [value] is null. */
    private fun JsonObject.withField(key: String, value: JsonElement?): JsonObject {
        val fields = toMutableMap()
        if (value == null) fields.remove(key) else fields[key] = value
        return JsonObject(fields)
    }

    private fun JsonObject.items() = getValue("items").jsonArray.map { it.jsonObject }

    private fun JsonObject.text(key: String) = getValue(key).jsonPrimitive.content

    private fun JsonObject.editCategory(position: Int, edit: (JsonObject) -> JsonObject): JsonObject {
        val categories = getValue("categories").jsonArray.map { it.jsonObject }
        return withField(
            "categories",
            JsonArray(
                categories.mapIndexed { i, it ->
                    if (i ==
                        position
                    ) {
                        edit(it)
                    } else {
                        it
                    }
                }
            )
        )
    }

    /** This menu with its first item that matches [where] edited. Fails when no item matches. */
    private fun JsonObject.editFirstItem(
        where: (JsonObject) -> Boolean = { true },
        edit: (JsonObject) -> JsonObject
    ): JsonObject {
        var edited = false
        val categories = getValue("categories").jsonArray.map { element ->
            val category = element.jsonObject
            category.withField(
                "items",
                JsonArray(
                    category.items().map { item ->
                        if (!edited && where(item)) item.also { edited = true }.let(edit) else item
                    }
                )
            )
        }
        check(edited) { "No item to break in menu ${text("restaurant_id")}" }
        return withField("categories", JsonArray(categories))
    }
}

package com.effekt3r.mrd.tools.datagen

import java.io.File
import java.net.URI
import java.net.http.HttpClient
import java.net.http.HttpRequest
import java.net.http.HttpResponse
import java.time.Duration

/**
 * The generator's entry point, run from the repository root by Gradle. `./gradlew :tools:datagen:run` writes both
 * datasets and the menus from the committed image pool, with no network. `--args=fetch-images` refreshes the pool
 * from TheMealDB, the only command that needs the network.
 */
fun main(args: Array<String>) {
    check(File("tools/datagen").isDirectory) {
        "Run the generator from the repository root, through Gradle: ./gradlew :tools:datagen:run"
    }
    when (args.singleOrNull()) {
        "generate" -> generate()
        "fetch-images" -> fetchImages()
        else -> error("Unknown command '${args.joinToString(" ")}'. Use generate (the default) or fetch-images.")
    }
}

private fun generate() {
    val pool = ImagePool.load()
    Dataset.entries.forEach { dataset ->
        val text = dataset.render(pool)
        File(dataset.path).apply { parentFile.mkdirs() }.writeText(text)
        println("Wrote ${dataset.path}: ${dataset.size} restaurants, ${text.toByteArray().size} bytes")
    }
    val menus = MenuGenerator.files(pool)
    val deleted = MenuGenerator.write(File(MenuGenerator.DIRECTORY), menus)
    val bytes = menus.values.sumOf { it.toByteArray().size }
    println("Wrote ${MenuGenerator.DIRECTORY}/: ${menus.size} menus, $bytes bytes")
    deleted.forEach { println("Deleted ${MenuGenerator.DIRECTORY}/$it: no restaurant has that id") }
}

private fun fetchImages() {
    val text = ImagePoolFetcher.fetch(::httpGet)
    File(ImagePool.SOURCE_PATH).writeText(text)
    ImagePool.parse(text).photos.forEach { (key, photos) -> println("$key: ${photos.size} photos") }
    println("Wrote ${ImagePool.SOURCE_PATH}")
}

// Built on first use, so `generate` never starts the HTTP stack.
private val client: HttpClient by lazy { HttpClient.newBuilder().connectTimeout(Duration.ofSeconds(10)).build() }

/** GETs [url] and returns the body. Anything but HTTP 200 stops the run, so a partial pool is never written. */
private fun httpGet(url: String): String {
    val request = HttpRequest.newBuilder(URI.create(url)).timeout(Duration.ofSeconds(30)).build()
    val response = client.send(request, HttpResponse.BodyHandlers.ofString())
    check(response.statusCode() == 200) { "GET $url returned HTTP ${response.statusCode()}" }
    return response.body()
}
