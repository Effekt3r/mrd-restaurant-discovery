# Milestone 2: mock API, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The mock API's data, served from this repository over HTTPS:
- 220 generated restaurants in `mock-api/v1/restaurants.json`, and a 10,000-restaurant stress file;
- deterministic and deliberately messy, with the edge cases milestone 3's validation needs;
- then the first release from `dev` to `master` (`v0.1.0`), so release builds will have an API to call.

**Architecture:**
- **`:tools:datagen`** is a small pure Kotlin module that never ships in the app: the `mrd.jvm.library` convention plus Gradle's `application` plugin. `./gradlew :tools:datagen:run` writes both files. `--args=fetch-images` refreshes the image pool from TheMealDB, the only step that needs the network.
- **Determinism.** Restaurant *i* draws from its own `Random(SEED * 31 + i)`, so it depends only on the seed, *i* and the names before it. The stress file's first 220 restaurants are the 220-restaurant file, and regenerating changes no byte.
- **Exact JSON.** Records are built with kotlinx.serialization's `JsonObject` builders (no compiler plugin) and written by a small writer, so missing keys, explicit nulls and wrong types are exactly what the edge cases need.
- **A golden test** compares the committed files with the generator's output byte for byte. Its Gradle task declares `mock-api/` as an input, so Gradle can't skip it.

**Tech stack:** Kotlin 2.3.21 on the JVM (JDK 17 API), Gradle's `application` plugin, kotlinx.serialization JSON 1.11.0, `java.net.http.HttpClient`, JUnit 4.13.2, TheMealDB's free API, `raw.githubusercontent.com`.

**Spec:** `docs/specs/2026-11-18-restaurant-discovery-design.md`, §5.1, §5.2, §5.3, §5.6, §5.7 and §11 (AC-2, AC-14, AC-15, AC-16). **Roadmap:** `docs/plans/2026-11-18-00-roadmap.md`.

**Branch:** `feature/mock-api`, cut from `dev`. It ends in one pull request into `dev`; Task 10 then releases `dev` to `master`. Run every command from the repository root.

- **Replay:** a second clean clone then followed Tasks 1 to 8 literally, taking every file from this plan's code blocks. All 48 checks of the expected output passed, and the result was byte-identical to the spike. It reused the spike's image pool rather than calling TheMealDB again.
- **Changes from the design**, each proven in the spike:
  - **TheMealDB's areas.** Filtering by the demonyms that `list.php?a=list` returns finds nothing for American, Indian, Lebanese and South African: those meals are filed under country names (`United States`, `India`), and TheMealDB has no South African dishes at all.   - **One fee draw.** Free delivery is drawn once, together with the missing fee, so it's 15% of all restaurants rather than 15% of those with a fee (which measured 13.8%).

## Before you start

- **JDK 21:** on the `PATH` or in `JAVA_HOME` (`export JAVA_HOME=$(/usr/libexec/java_home -v 21)` on macOS).
- **Android SDK:** platform 36 and build-tools 36. Either `ANDROID_HOME` is set, or a git-ignored `local.properties` contains `sdk.dir=<absolute path to the SDK>`.
- **Network:** Task 2's `fetch-images` makes 24 requests to TheMealDB. Tasks 9 and 10 use GitHub. Nothing else needs the network.
- **Versions:** don't change any. The one new library, `kotlinx-serialization-json`, uses the catalog's existing `kotlinxSerialization` version (1.11.0). Its POM needs `kotlin-stdlib` 2.3.20, which is within the project's 2.3.21.
- **Formatting:** run `./gradlew spotlessApply` before every commit. The code below is already formatted.
- **Commits** have a conventional subject, the reason in the body and a `Verified:` line, and Franco is the author. Add no AI trailers: no `Co-Authored-By` or `Claude-Session` lines.
- **Generated files:** never edit `mock-api/v1/*.json` or `image-pool.json` by hand; regenerate them.
- **Tests:** `./gradlew :tools:datagen:test` runs this module's tests, and `./gradlew testDebugUnitTest` includes them. This counts the results:

  ```bash
  cat tools/datagen/build/test-results/test/*.xml | grep -o '<testsuite [^>]*' \
  ```

```kotlin
package com.effekt3r.mrd.tools.datagen

import kotlinx.serialization.json.Json
import kotlinx.serialization.json.JsonArray
import kotlinx.serialization.json.JsonElement
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.JsonPrimitive

/**
 * Writes JSON the same way every time: keys in insertion order, LF line endings and one trailing newline. Whoever
 * builds the [JsonObject] decides what's missing (a key left out) and what's an explicit `null` (`JsonNull`).
 * kotlinx.serialization escapes the strings; non-ASCII text such as "Café" is written as UTF-8.
 */
internal object JsonWriter {

    private const val INDENT = "  "

    /** The longest object or array that [pretty] keeps on one line. */
    private const val ONE_LINE_WIDTH = 80

    /** One line with no spaces, for the 10,000-restaurant file, where size matters more than reading it. */
    fun compact(element: JsonElement): String = Json.encodeToString(JsonElement.serializer(), element) + "\n"

    /**
     * Two-space indents, for files people read. An object or array that holds only values (no nested objects or
     * arrays) stays on one line when it fits, so cuisines and opening-hours entries read like spec §5.1's example.
     */
    fun pretty(element: JsonElement): String = buildString {
        appendPretty(element, depth = 0)
        append('\n')
    }

    private fun StringBuilder.appendPretty(element: JsonElement, depth: Int) {
        val oneLine = oneLine(element)
        when {
            oneLine != null -> append(oneLine)
            element is JsonObject -> appendBlock("{", "}", element.entries, depth) { (key, value) ->
                append(JsonPrimitive(key)).append(": ")
                appendPretty(value, depth + 1)
            }
            element is JsonArray -> appendBlock("[", "]", element, depth) { appendPretty(it, depth + 1) }
        }
    }

    private fun <T> StringBuilder.appendBlock(
        open: String,
        close: String,
        items: Collection<T>,
        depth: Int,
        appendItem: StringBuilder.(T) -> Unit
    ) {
        append(open).append('\n')
        items.forEachIndexed { index, item ->
            append(INDENT.repeat(depth + 1))
            appendItem(item)
            if (index < items.size - 1) append(',')
            append('\n')
        }
        append(INDENT.repeat(depth)).append(close)
    }

    /** [element] on one line, or null when it holds an object or array or is too long. Values always fit. */
    private fun oneLine(element: JsonElement): String? = when (element) {
        is JsonPrimitive -> element.toString()
        is JsonArray -> if (element.all { it is JsonPrimitive }) element.joinToString(", ", "[", "]") else null
        is JsonObject -> when {
            element.isEmpty() -> "{}"
            element.values.all { it is JsonPrimitive } ->
                element.entries.joinToString(", ", "{ ", " }") { (key, value) -> "${JsonPrimitive(key)}: $value" }
            else -> null
        }
    }?.takeIf { element is JsonPrimitive || it.length <= ONE_LINE_WIDTH }
}
```

```kotlin
package com.effekt3r.mrd.tools.datagen

import kotlin.random.Random
import kotlinx.serialization.json.Json
import kotlinx.serialization.json.jsonArray
import kotlinx.serialization.json.jsonObject
import kotlinx.serialization.json.jsonPrimitive

/**
 * TheMealDB photo URLs by image key, from the committed image-pool.json. Generating reads this file rather than the
 * network, so it's repeatable and works offline. Being a resource on the classpath, it's also a Gradle input of both
 * the run task and the tests.
 */
internal class ImagePool(val photos: Map<String, List<String>>) {

    fun pick(key: String, random: Random): String = photosFor(key).random(random)

    fun first(key: String): String = photosFor(key).first()

    private fun photosFor(key: String) = photos[key] ?: error("$RESOURCE has no image key '$key'")

    companion object {
        const val RESOURCE = "image-pool.json"

        /** Where fetch-images writes the pool, relative to the repository root. */
        const val SOURCE_PATH = "tools/datagen/src/main/resources/$RESOURCE"

        fun load(): ImagePool = parse(resourceText())

        fun resourceText(): String = ImagePool::class.java.getResource("/$RESOURCE")?.readText()
            ?: error("$RESOURCE is missing. Run ./gradlew :tools:datagen:run --args=fetch-images")

        fun parse(json: String) = ImagePool(
            Json.parseToJsonElement(json).jsonObject.mapValues { (_, photos) ->
                photos.jsonArray.map { it.jsonPrimitive.content }
            }
        )
    }
}
```

```kotlin
import kotlinx.serialization.json.Json
import kotlinx.serialization.json.JsonArray
import kotlinx.serialization.json.JsonNull
import kotlinx.serialization.json.JsonPrimitive
import kotlinx.serialization.json.buildJsonObject
import kotlinx.serialization.json.jsonArray
import kotlinx.serialization.json.jsonObject
import kotlinx.serialization.json.jsonPrimitive

/** Builds image-pool.json from TheMealDB's free API. The only part of the generator that uses the network. */
internal object ImagePoolFetcher {

    /**
     * The queries behind each image key: `c=` a category, `a=` an area, `s=` a search by meal name. Some areas need
     * the country's name (India, United States): list.php?a=list returns demonyms, but meals filed under those
     * countries carry the country's name, and the demonym finds nothing. TheMealDB has no South African dishes, so
     * there's no key for them.
     */
    val QUERIES: Map<String, List<String>> = mapOf(
        "american" to listOf("a=United States"),
        "beef" to listOf("c=Beef"),
        "breakfast" to listOf("c=Breakfast"),
        "chicken" to listOf("c=Chicken"),
        "chinese" to listOf("a=Chinese"),
        "dessert" to listOf("c=Dessert"),
        "greek" to listOf("a=Greek"),
        "indian" to listOf("a=India"),
        "italian" to listOf("a=Italian"),
        "japanese" to listOf("a=Japanese"),
        "lamb" to listOf("c=Lamb"),
        "mexican" to listOf("a=Mexican"),
        "middle-eastern" to listOf("a=Turkish", "a=Moroccan", "a=Egyptian"),
        "pasta" to listOf("c=Pasta"),
        "pizza" to listOf("s=pizza", "s=flatbread", "s=lahmacun"),
        "portuguese" to listOf("a=Portuguese"),
        "seafood" to listOf("c=Seafood"),
        "thai" to listOf("a=Thai"),
        "vegan" to listOf("c=Vegan", "c=Vegetarian")
    )

    const val MIN_PHOTOS = 5

    /** A photo URL as the API returns it: HTTPS, with no size suffix such as /medium (the app adds that). */
    val PHOTO_URL = Regex("""^https://www\.themealdb\.com/images/media/meals/[^/]+\.jpg$""")

    // The free API's public test key, "1".
    private const val API = "https://www.themealdb.com/api/json/v1/1"

    /**
     * Runs every query through [get] (a URL in, the response body out) and returns image-pool.json's text: keys
     * sorted, each key's photos sorted and distinct. URLs that aren't canonical are skipped, and any key left with
     * fewer than [MIN_PHOTOS] photos fails the fetch, naming every such key.
     */
    fun fetch(get: (String) -> String): String {
        val pool = QUERIES.toSortedMap().mapValues { (_, queries) ->
            val (canonical, skipped) = queries.flatMap { photos(get(url(it))) }.distinct().partition(PHOTO_URL::matches)
            skipped.forEach { println("Skipped a photo URL that isn't canonical: $it") }
            canonical.sorted()
        }
        val short = pool.filterValues { it.size < MIN_PHOTOS }
        check(short.isEmpty()) {
            "Every image key needs at least $MIN_PHOTOS photos. Add a query for " +
                short.entries.joinToString { (key, photos) -> "'$key' (${photos.size})" }
        }
        return JsonWriter.pretty(
            buildJsonObject { pool.forEach { (key, photos) -> put(key, JsonArray(photos.map(::JsonPrimitive))) } }
        )
    }

    /** The request URL for a query such as "a=United States". */
    fun url(query: String): String {
        val (parameter, value) = query.split('=', limit = 2)
        val endpoint = when (parameter) {
            "a", "c" -> "filter.php"
            "s" -> "search.php"
            else -> error("Unknown TheMealDB query '$query'")
        }
        return "$API/$endpoint?$parameter=" + URLEncoder.encode(value, Charsets.UTF_8).replace("+", "%20")
    }

    /** The photo URLs in a filter.php or search.php response. `{"meals":null}` means no results. */
    fun photos(response: String): List<String> {
        val meals = Json.parseToJsonElement(response).jsonObject["meals"]
        if (meals == null || meals is JsonNull) return emptyList()
        return meals.jsonArray.map { it.jsonObject.getValue("strMealThumb").jsonPrimitive.content }
    }
}
```

```kotlin
/**
 * The generator's entry point, run from the repository root by Gradle. `--args=fetch-images` refreshes the image pool
 * from TheMealDB, the only command that needs the network.
 */
fun main(args: Array<String>) {
    check(File("tools/datagen").isDirectory) {
        "Run the generator from the repository root, through Gradle: ./gradlew :tools:datagen:run"
    }
    when (args.singleOrNull()) {
        "fetch-images" -> fetchImages()
        else -> error("Unknown command '${args.joinToString(" ")}'. The only command so far is fetch-images.")
    }
}

private fun fetchImages() {
    val text = ImagePoolFetcher.fetch(::httpGet)
    File(ImagePool.SOURCE_PATH).writeText(text)
    ImagePool.parse(text).photos.forEach { (key, photos) -> println("$key: ${photos.size} photos") }
    println("Wrote ${ImagePool.SOURCE_PATH}")
}

private val client: HttpClient = HttpClient.newBuilder().connectTimeout(Duration.ofSeconds(10)).build()

/** GETs [url] and returns the body. Anything but HTTP 200 stops the run, so a partial pool is never written. */
private fun httpGet(url: String): String {
    val request = HttpRequest.newBuilder(URI.create(url)).timeout(Duration.ofSeconds(30)).build()
    val response = client.send(request, HttpResponse.BodyHandlers.ofString())
    check(response.statusCode() == 200) { "GET $url returned HTTP ${response.statusCode()}" }
    return response.body()
}
```

```kotlin
package com.effekt3r.mrd.tools.datagen

import java.time.DayOfWeek
import java.time.DayOfWeek.FRIDAY
import java.time.DayOfWeek.MONDAY
import java.time.DayOfWeek.SATURDAY
import java.time.DayOfWeek.SUNDAY
import java.time.DayOfWeek.TUESDAY
import kotlin.random.Random
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.buildJsonObject
import kotlinx.serialization.json.put

internal const val MINUTES_PER_DAY = 24 * 60
internal const val MINUTES_PER_WEEK = 7 * MINUTES_PER_DAY

/** Minutes after midnight: `at(11, 30)` is 11:30. */
internal fun at(hour: Int, minute: Int = 0) = hour * 60 + minute

/**
 * One opening window in the restaurant's local time (Africa/Johannesburg), in minutes after midnight. [closes] may be
 * 1440 ("24:00"), or earlier than [opens] when the window runs past midnight into the next day.
 */
internal data class OpeningHours(val day: DayOfWeek, val opens: Int, val closes: Int) {

    fun toJson(): JsonObject = buildJsonObject {
        put("day", day.name)
        put("opens", clock(opens))
        put("closes", clock(closes))
    }

    // "HH:mm", padded by hand: String.format would use the machine's locale, which could change the digits.
    private fun clock(minutes: Int) =
        (minutes / 60).toString().padStart(2, '0') + ":" + (minutes % 60).toString().padStart(2, '0')
}

/** The weekly patterns a restaurant's opening hours follow (spec §5.2). Every time is on a 15-minute grid. */
internal enum class HoursStyle {
    /** One window a day, opening 10:00 to 12:00 and closing 21:00 to 23:00. About one in five closes one weekday. */
    STANDARD,

    /** Lunch and dinner shifts every day. About one in five closes on Mondays. */
    SPLIT,

    /** Open late, and until 02:00 on Friday and Saturday nights. Half close at 01:00 on Sunday night (Monday). */
    LATE_NIGHT,

    /** Open around the clock: 00:00 to 24:00 every day. */
    ALL_DAY,

    /** A breakfast café, open from about 07:00 to 15:00. */
    BREAKFAST
}

internal object Hours {

    fun generate(style: HoursStyle, random: Random): List<OpeningHours> = when (style) {
        HoursStyle.STANDARD -> standard(random)
        HoursStyle.SPLIT -> split(random)
        HoursStyle.LATE_NIGHT -> lateNight(random)
        HoursStyle.ALL_DAY -> DayOfWeek.entries.map { OpeningHours(it, 0, MINUTES_PER_DAY) }
        HoursStyle.BREAKFAST -> breakfast(random)
    }

    private fun standard(random: Random): List<OpeningHours> {
        val opens = random.oneOf(at(10), at(10, 30), at(11), at(11, 30), at(12))
        val closes = random.oneOf(at(21), at(21, 30), at(21, 45), at(22), at(22, 30), at(23))
        val closedDay = if (random.nextInt(100) < 20) random.oneOf(MONDAY, MONDAY, TUESDAY) else null
        return DayOfWeek.entries.filter { it != closedDay }.map { OpeningHours(it, opens, closes) }
    }

    private fun split(random: Random): List<OpeningHours> {
        val lunch = random.oneOf(at(11, 30), at(12)) to random.oneOf(at(14, 30), at(15))
        val dinner = random.oneOf(at(17, 30), at(18)) to random.oneOf(at(21, 30), at(22), at(22, 30))
        val closedDay = if (random.nextInt(100) < 20) MONDAY else null
        return DayOfWeek.entries.filter { it != closedDay }.flatMap { day ->
            listOf(OpeningHours(day, lunch.first, lunch.second), OpeningHours(day, dinner.first, dinner.second))
        }
    }

    private fun lateNight(random: Random): List<OpeningHours> {
        val opens = random.oneOf(at(11), at(12))
        val closes = random.oneOf(at(23), at(23, 30), at(24))
        // Closing at 01:00 on Sunday night is the Sunday-to-Monday wrap: it ends in the first hour of the week.
        val sundayCloses = if (random.nextBoolean()) at(1) else closes
        return DayOfWeek.entries.map { day ->
            when (day) {
                FRIDAY, SATURDAY -> OpeningHours(day, opens, at(2))
                SUNDAY -> OpeningHours(day, opens, sundayCloses)
                else -> OpeningHours(day, opens, closes)
            }
        }
    }

    private fun breakfast(random: Random): List<OpeningHours> {
        val opens = random.oneOf(at(6, 30), at(7), at(7), at(7, 30))
        val closes = random.oneOf(at(14), at(15), at(15), at(16))
        return DayOfWeek.entries.map { OpeningHours(it, opens, closes) }
    }
}

/**
 * Whether a window covers [weekMinute], where 0 is Monday 00:00 (spec §5.6's model). A window that runs past
 * midnight continues into the next day, and one that runs past Sunday midnight continues at the start of the week.
 */
internal fun List<OpeningHours>.isOpenAt(weekMinute: Int): Boolean = any { (day, opens, closes) ->
    val dayStart = day.ordinal * MINUTES_PER_DAY
    val start = dayStart + opens
    val end = dayStart + if (closes > opens) closes else closes + MINUTES_PER_DAY
    weekMinute in start until end || weekMinute + MINUTES_PER_WEEK in start until end
}

/** One of [options], each equally likely. List an option twice to make it twice as likely. */
internal fun <T> Random.oneOf(vararg options: T): T = options[nextInt(options.size)]
```

```kotlin
import kotlin.random.Random

/** Cape Town suburbs, landmarks and local words. A generated name is "{place} {noun}"; none is a real business. */
internal val PLACES = listOf(
    "Bakoven", "Bloubergstrand", "Bo-Kaap", "Bree Street", "Camps Bay", "Cape Point", "Chapman's Peak", "Clifton",
    "Constantia", "Dassie", "De Waterkant", "Devil's Peak", "False Bay", "Fish Hoek", "Fynbos", "Gardens",
    "Green Point", "Hout Bay", "Kalk Bay", "Kirstenbosch", "Kloof Street", "Kommetjie", "Lion's Head", "Llandudno",
    "Long Street", "Mouille Point", "Muizenberg", "Newlands", "Noordhoek", "Observatory", "Oranjezicht", "Protea",
    "Rondebosch", "Salt River", "Scarborough", "Sea Point", "Signal Hill", "Simon's Town", "Southeaster", "Tafelberg",
    "Tamboerskloof", "Two Oceans", "Woodstock", "Wynberg"
)

/**
 * Hands out names in restaurant order. The first [uniqueCount] are unique: a name already taken is drawn again, so
 * each depends only on its restaurant's Random and the names before it. Later names may repeat, as chains' do.
 */
internal class NameBook(private val uniqueCount: Int) {

    private val taken = mutableSetOf<String>()

    fun next(index: Int, concept: Concept, random: Random): String {
        repeat(MAX_ATTEMPTS) {
            val name = "${PLACES.random(random)} ${concept.nouns.random(random)}"
            if (index >= uniqueCount || taken.add(name)) return name
        }
        error("No unique name for restaurant $index after $MAX_ATTEMPTS attempts. Add places or nouns.")
    }

    private companion object {
        const val MAX_ATTEMPTS = 100
    }
}
```

```kotlin
package com.effekt3r.mrd.tools.datagen

import java.time.DayOfWeek
import java.time.DayOfWeek.FRIDAY
import java.time.DayOfWeek.SATURDAY
import java.time.DayOfWeek.SUNDAY
import kotlin.random.Random
import kotlinx.serialization.json.JsonObject

/**
 * Generates the restaurants. Restaurant i draws from its own Random(SEED * 31 + i), so it depends only on the seed,
 * its index and the names before it: generating twice gives the same restaurants, and the first 220 of 10,000 are
 * exactly the 220 of the standard dataset. kotlin.random only promises the same sequence within one Kotlin version,
 * so a Kotlin upgrade may change the data. GoldenFilesTest then fails, and regenerating is the fix.
 */
internal object Generator {

    const val SEED = 20_261_118L

    /** Friday 19:00 in Cape Town: the moment `is_open` describes, like a server snapshot that's never refreshed. */
    val SNAPSHOT_WEEK_MINUTE = FRIDAY.ordinal * MINUTES_PER_DAY + at(19)

    // Spec §5.2's rates, in percent, each drawn per restaurant.
    private const val NO_RATING_PERCENT = 6
    private const val NO_FEE_PERCENT = 4
    private const val FREE_DELIVERY_PERCENT = 15
    private const val NO_ETA_PERCENT = 4
    private const val NO_IMAGE_PERCENT = 6

    // 5% have no hours: 4% leave the key out and 1% send [].
    private const val NO_HOURS_PERCENT = 5
    private const val EMPTY_HOURS_PERCENT = 1

    // Without hours, `is_open` is all there is.
    private const val OPEN_WITHOUT_HOURS_PERCENT = 70

    fun restaurants(count: Int, pool: ImagePool): List<JsonObject> {
        val names = NameBook(uniqueCount = Dataset.STANDARD.size)
        return List(count) { index -> EdgeCases.apply(index, restaurant(index, names, pool).toJson()) }
    }

    fun idFor(index: Int) = "r-${1001 + index}"

    private fun restaurant(index: Int, names: NameBook, pool: ImagePool): Restaurant {
        if (index == 0) return capeTownGrill(pool)
        val random = Random(SEED * 31 + index)

        // Edge cases keep every field, so each one has only the defect EdgeCases gives it.
        val complete = index in EdgeCases.indexes
        fun missing(percent: Int) = !complete && random.nextInt(100) < percent

        val pinned = EdgeCases.pinnedNames[index]
        val concept = pinned?.let { Concepts.named(it.conceptKey) } ?: Concepts.pick(random)
        val name = pinned?.name ?: names.next(index, concept, random)
        val menu = concept.menus.random(random)
        val rating = if (missing(NO_RATING_PERCENT)) null else (32..49).random(random) / 10.0
        // One draw sets the fee, so free delivery is 15% of all restaurants, not of those with a fee.
        val feeDraw = random.nextInt(100)
        val deliveryFeeCents = when {
            feeDraw < NO_FEE_PERCENT && !complete -> null
            feeDraw >= 100 - FREE_DELIVERY_PERCENT -> 0
            else -> concept.feesCents.random(random)
        }
        val etaMinutes = if (missing(NO_ETA_PERCENT)) null else concept.etaMinutes.random(random)
        val imageUrl = if (missing(NO_IMAGE_PERCENT)) null else pool.pick(menu.imageKey, random)
        val openingHours = when {
            !missing(NO_HOURS_PERCENT) -> Hours.generate(concept.hours.random(random), random)
            random.nextInt(NO_HOURS_PERCENT) < EMPTY_HOURS_PERCENT -> emptyList()
            else -> null
        }
        val isOpen = if (openingHours.isNullOrEmpty()) {
            random.nextInt(100) < OPEN_WITHOUT_HOURS_PERCENT
        } else {
            openingHours.isOpenAt(SNAPSHOT_WEEK_MINUTE)
        }
        return Restaurant(
            idFor(index), name, menu.cuisines, rating, deliveryFeeCents, etaMinutes, isOpen, imageUrl, openingHours
        )
    }

    /** r-1001 is the brief's example, which the app's placeholder already shows. */
    private fun capeTownGrill(pool: ImagePool): Restaurant {
        val hours = DayOfWeek.entries.map { day ->
            when (day) {
                FRIDAY, SATURDAY -> OpeningHours(day, at(11), at(2))
                SUNDAY -> OpeningHours(day, at(11), at(21))
                else -> OpeningHours(day, at(11), at(22))
            }
        }
        return Restaurant(
            id = idFor(0),
            name = "Cape Town Grill",
            cuisines = listOf("Steakhouse", "Grill"),
            rating = 4.6,
            deliveryFeeCents = 1500,
            etaMinutes = 32,
            isOpen = hours.isOpenAt(SNAPSHOT_WEEK_MINUTE),
            imageUrl = pool.first("beef"),
            openingHours = hours
        )
    }
}
```

```kotlin
package com.effekt3r.mrd.tools.datagen

import kotlinx.serialization.json.JsonArray
import kotlinx.serialization.json.JsonElement
import kotlinx.serialization.json.JsonNull
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.JsonPrimitive
import kotlinx.serialization.json.buildJsonObject
import kotlinx.serialization.json.jsonArray
import kotlinx.serialization.json.jsonPrimitive
import kotlinx.serialization.json.put

/**
 * Deliberately broken restaurants at fixed indexes below 220, so both datasets carry them. Each keeps every other
 * field valid, so milestone 3's validation tests know exactly why a record is dropped or what's repaired.
 * mock-api/README.md lists them with their ids.
 */
internal object EdgeCases {

    // Required by spec §5.2. The app drops these records.
    const val MISSING_ID = 10
    const val BLANK_NAME = 20
    const val DUPLICATE_ID = 30

    /** The earlier restaurant whose id [DUPLICATE_ID] repeats. */
    const val DUPLICATE_ID_SOURCE = 29

    // For milestone 3's validation tests (AC-14). The app keeps these records and treats the bad value as missing.
    const val RATING_OUT_OF_RANGE = 40
    const val RATING_NULL = 50
    const val RATING_AS_STRING = 60
    const val NEGATIVE_FEE = 70
    const val ZERO_ETA = 80
    const val HTTP_IMAGE = 90
    const val EMPTY_HOURS = 100
    const val HOURS_OPEN_EQUALS_CLOSE = 110
    const val HOURS_UNKNOWN_DAY = 120
    const val HOURS_INVALID_TIME = 130
    const val MESSY_CUISINES = 140
    const val UNKNOWN_STATUS = 150

    // Valid restaurants whose names test search: a LIKE wildcard to escape, and an accent to ignore.
    const val PERCENT_IN_NAME = 160
    const val ACCENTED_NAME = 170

    val indexes = setOf(
        MISSING_ID, BLANK_NAME, DUPLICATE_ID, RATING_OUT_OF_RANGE, RATING_NULL, RATING_AS_STRING, NEGATIVE_FEE,
        ZERO_ETA, HTTP_IMAGE, EMPTY_HOURS, HOURS_OPEN_EQUALS_CLOSE, HOURS_UNKNOWN_DAY, HOURS_INVALID_TIME,
        MESSY_CUISINES, UNKNOWN_STATUS, PERCENT_IN_NAME, ACCENTED_NAME
    )

    /** A name an edge case fixes, and the concept whose cuisines, hours and photo suit it. */
    class PinnedName(val name: String, val conceptKey: String)

    val pinnedNames = mapOf(
        PERCENT_IN_NAME to PinnedName("100% Plant Kitchen", "healthy"),
        ACCENTED_NAME to PinnedName("Café Fynbos", "cafe")
    )

    fun apply(index: Int, record: JsonObject): JsonObject = when (index) {
        MISSING_ID -> record.withField("id", null)
        BLANK_NAME -> record.withField("name", JsonPrimitive("   "))
        DUPLICATE_ID -> record.withField("id", JsonPrimitive(Generator.idFor(DUPLICATE_ID_SOURCE)))
        RATING_OUT_OF_RANGE -> record.withField("rating", JsonPrimitive(5.4))
        RATING_NULL -> record.withField("rating", JsonNull)
        RATING_AS_STRING -> record.withField("rating", JsonPrimitive("4.5"))
        NEGATIVE_FEE -> record.withField("delivery_fee_cents", JsonPrimitive(-500))
        ZERO_ETA -> record.withField("eta_minutes", JsonPrimitive(0))
        HTTP_IMAGE -> record.withField("image_url", JsonPrimitive(record.text("image_url").replace("https:", "http:")))
        EMPTY_HOURS -> record.withField("opening_hours", JsonArray(emptyList()))
        HOURS_OPEN_EQUALS_CLOSE -> record.withHoursEntry("WEDNESDAY", "15:00", "15:00")
        HOURS_UNKNOWN_DAY -> record.withHoursEntry("FUNDAY", "10:00", "22:00")
        HOURS_INVALID_TIME -> record.withHoursEntry("SATURDAY", "10:00", "25:00")
        MESSY_CUISINES -> {
            val cuisines = record.getValue("cuisines").jsonArray
            val blank = JsonPrimitive(" ")
            val empty = JsonPrimitive("")
            record.withField("cuisines", JsonArray(listOf(cuisines[0], blank, cuisines[0], empty) + cuisines.drop(1)))
        }
        UNKNOWN_STATUS -> record.withField("is_open", null).withField("opening_hours", null)
        else -> record
    }

    /** This record with [key] set to [value], or left out when [value] is null, in spec §5.1's key order. */
    private fun JsonObject.withField(key: String, value: JsonElement?): JsonObject {
        val fields = toMutableMap()
        if (value == null) fields.remove(key) else fields[key] = value
        return JsonObject(Restaurant.KEYS.mapNotNull { name -> fields[name]?.let { name to it } }.toMap())
    }

    /** This record with one more opening-hours entry after its valid ones. */
    private fun JsonObject.withHoursEntry(day: String, opens: String, closes: String): JsonObject {
        val entry = buildJsonObject {
            put("day", day)
            put("opens", opens)
            put("closes", closes)
        }
        return withField("opening_hours", JsonArray(getValue("opening_hours").jsonArray + entry))
    }

    private fun JsonObject.text(key: String) = getValue(key).jsonPrimitive.content
}
```

```kotlin
package com.effekt3r.mrd.tools.datagen

import java.io.File
import java.net.URI
import java.net.http.HttpClient
import java.net.http.HttpRequest
import java.net.http.HttpResponse
import java.time.Duration

/**
 * The generator's entry point, run from the repository root by Gradle. `./gradlew :tools:datagen:run` writes both
 * datasets from the committed image pool, with no network. `--args=fetch-images` refreshes the pool from TheMealDB,
 * the only command that needs the network.
 */
fun main(args: Array<String>) {
    check(File("tools/datagen").isDirectory) {
        "Run the generator from the repository root, through Gradle: ./gradlew :tools:datagen:run"
    }
    when (args.singleOrNull()) {
        "generate" -> generate()
        "fetch-images" -> fetchImages()
        else -> error("Unknown command '${args.joinToString(" ")}'. Use generate (the default) or fetch-images.")
    }
}

private fun generate() {
    val pool = ImagePool.load()
    Dataset.entries.forEach { dataset ->
        val text = dataset.render(pool)
        File(dataset.path).apply { parentFile.mkdirs() }.writeText(text)
        println("Wrote ${dataset.path}: ${dataset.size} restaurants, ${text.toByteArray().size} bytes")
    }
}

private fun fetchImages() {
    val text = ImagePoolFetcher.fetch(::httpGet)
    File(ImagePool.SOURCE_PATH).writeText(text)
    ImagePool.parse(text).photos.forEach { (key, photos) -> println("$key: ${photos.size} photos") }
    println("Wrote ${ImagePool.SOURCE_PATH}")
}

private val client: HttpClient = HttpClient.newBuilder().connectTimeout(Duration.ofSeconds(10)).build()

/** GETs [url] and returns the body. Anything but HTTP 200 stops the run, so a partial pool is never written. */
private fun httpGet(url: String): String {
    val request = HttpRequest.newBuilder(URI.create(url)).timeout(Duration.ofSeconds(30)).build()
    val response = client.send(request, HttpResponse.BodyHandlers.ofString())
    check(response.statusCode() == 200) { "GET $url returned HTTP ${response.statusCode()}" }
    return response.body()
}
```

````markdown
# Mock API

The restaurant data the app reads: static JSON, served over HTTPS by `raw.githubusercontent.com`. It stands in for a REST endpoint. The data is generated by `:tools:datagen`, and everything in it is fictional.

## Endpoints

`dev` plays the part of staging and `master` of production (spec §5.1). From milestone 3, debug builds will read `dev` and release builds `master`, and `-Pmrd.dataset=10k` will switch a debug build to the stress file.

| Environment | Restaurants (220) | Stress test (10,000) |
|---|---|---|
| Staging (`dev`) | https://raw.githubusercontent.com/Effekt3r/mrd-restaurant-discovery/dev/mock-api/v1/restaurants.json | https://raw.githubusercontent.com/Effekt3r/mrd-restaurant-discovery/dev/mock-api/v1/restaurants-10k.json |
| Production (`master`) | https://raw.githubusercontent.com/Effekt3r/mrd-restaurant-discovery/master/mock-api/v1/restaurants.json | https://raw.githubusercontent.com/Effekt3r/mrd-restaurant-discovery/master/mock-api/v1/restaurants-10k.json |

How GitHub serves them:
- `content-type: text/plain; charset=utf-8`, not `application/json`, so a client mustn't insist on a JSON content type;
- `cache-control: max-age=300` and a strong `etag`: a request with `If-None-Match` gets a `304` with no body;
- gzip, when the request accepts it.

## Schema

Spec §5.1 defines the fields, and what the app does when one is missing or invalid.
- **Keys** come in this order: `id`, `name`, `cuisines`, `rating`, `delivery_fee_cents`, `eta_minutes`, `is_open`, `image_url`, `opening_hours`. A missing value leaves its key out.
- **Opening hours** are entries of `day`, `opens` and `closes`, in Cape Town time.
- **`is_open`** describes Friday 19:00 in Cape Town, as if the server's snapshot had never been refreshed. For most of the week it's wrong, which is the staleness spec §5.6 is about: the app works the status out from the hours instead.

## Regenerating

| Command | What it does |
|---|---|
| `./gradlew :tools:datagen:run` | Writes both files from the committed image pool, in about a second. No network. |
| `./gradlew :tools:datagen:run --args=fetch-images` | Refreshes `tools/datagen/src/main/resources/image-pool.json` from TheMealDB. Regenerate afterwards. |

`GoldenFilesTest` fails when a committed file differs by a single byte from what the generator writes, so never edit these files by hand: change the generator, regenerate and commit both. The output depends only on the code, the image pool and the seed. One caveat: `kotlin.random` only promises the same sequence within one Kotlin version, so a Kotlin upgrade may change the data. The golden test then fails, and regenerating is the fix.

- **Names are fictional**: a Cape Town place and a noun, such as "Lion's Head Izakaya" (`r-1002`). A test fails if any name contains a South African chain or a well-known Cape Town restaurant (`RealNames.kt`). The first 220 names are unique; later ones repeat, as chains' do.
````
