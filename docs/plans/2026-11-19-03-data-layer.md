# Milestone 3: data layer, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the data layer behind both screens, with no UI change (Browse and Details stay placeholders until milestones 5 and 6):
- the brief's offline baseline: the restaurant list cached in Room as the single source of truth, refreshed from the mock API, paged, searchable, with favourites;
- the Task 3 improvement: "Open now" stays correct offline, because the status is worked out from the opening hours, in SQL for the list and in Kotlin for Details, and both are proven to agree;
- the menus (spec §5.9): fetched per restaurant, validated, and cached for offline use;
- the staleness measurement for SOLUTION.md.

**Architecture:**
- **`:core:model`** (pure Kotlin) holds immutable types: `RestaurantSummary`, `Restaurant`, `Money` (integer cents), `Rating` (tenths), `OpeningHours` as week-minute intervals, `OpenStatus` with the next change, `SyncStatus`, `SyncError`, the menu types and `MenuState`, plus the open-status rules Details uses.
- **`:core:common`** (pure Kotlin) holds the dispatchers, the application scope, the `Clock`, the minute ticker (a cold flow aligned to minute boundaries) and the `NetworkMonitor` interface, with their Hilt bindings.
- **`:core:network`** provides the shared `OkHttpClient` (10 MB cache, 10 s connect, 20 s read), the `Json` configuration and the `ConnectivityManager` implementation of `NetworkMonitor`.
- **`:core:data`:**
  - The API base URL and the dataset file are build-config values.
  - Parsing streams the payload and validates each record as it's read.
  - Room's `discovery.db` has five tables.
  - The list's status and Open now are computed in SQL from `:weekMinute` and `:now`.
  - The restaurant sync is single-flight. A 304 skips the write, and a new snapshot is swapped in one transaction.
  - The repositories' implementations are `internal`.
- **`:core:testing`** gives features public fakes, a test clock, a test ticker and a main-dispatcher rule.
- **Tests run on the JVM.** Room runs on Robolectric's SQLite, the network on MockWebServer, and paging through paging-testing.

**Tech stack:** Kotlin 2.3.21, Room 2.8.4 with KSP 2.3.9, Paging 3.4.2, Retrofit 3.0.0, OkHttp 5.3.2, kotlinx.serialization 1.11.0, kotlinx.coroutines 1.10.2, Hilt 2.59.2, Robolectric 4.16.1, androidx.test core 1.7.0, MockWebServer (`mockwebserver3`) 5.3.2, JUnit 4.13.2.

**Spec:** `docs/specs/2026-11-18-restaurant-discovery-design.md`, §5.1 to §5.9, §4.2 and §4.3, §7.1, and §11 (the logic behind AC-3, 9, 10, 11, 14, 15 and 24). **Roadmap:** `docs/plans/2026-11-18-00-roadmap.md`, milestone 3.

**Branch:** `feature/restaurant-data`, cut from `dev`, with this plan as its first commit. It ends in one pull request into `dev`. Run every command from the repository root.

## Spike results

A throwaway spike built this plan's code in a disposable clone on 2026-11-19 and ran its checks: the tests, the break-it probes, the full gate and an R8 build with a temporary caller. The code blocks below are copied from it. The final state was built and tested; the commits in between weren't replayed one by one, so their red steps are stated as expectations.
- **Room, KSP and Hilt:**
  - Room 2.8.4 with KSP 2.3.9 compiles with no warnings, generates Kotlin without an option, and exports `core/data/schemas/com.effekt3r.mrd.core.data.database.DiscoveryDatabase/1.json`.
  - Hilt modules compile in the pure Kotlin `:core:common`, because hilt-core has `SingletonComponent`.
  - With both repositories injected into `MrdApplication`, Hilt resolved the whole graph across `:core:common`, `:core:network` and `:core:data`. Without the `MenuRepository` binding, it failed with `[Dagger/MissingBinding]`. Task 10 repeats this.
- **Paging and the SQL status:**
  - 20 boundary cases give the expected status in Kotlin and in SQL, and SQL's Open now filter keeps exactly the restaurants it shows as Open.
  - Making the SQL include the closing minute fails 3 cases, with messages naming them.
  - A tick reloads the list in place: paging-testing's `asSnapshot` sees the new status within one collection. Removing the invalidation fails that test.
- **Tests on the JVM: Robolectric, not the bundled SQLite driver.**
  - Every builder in `room-runtime-android` 2.8.4 takes a `Context`. The context-free builders exist only in Room's JVM and native artifacts, which an Android module's unit tests don't resolve.
  - So the bundled driver would still need Robolectric for the `Context`, and would test a SQLite path that devices don't use.
  - Robolectric runs Room through the framework's SQLite code path, as a device does.
  - The first Robolectric test class in a run takes 4 to 6 seconds to start, and `:core:data`'s 36 tests take about 11 seconds.
  - No artifact outside the roadmap's version table is added.
- **R8, Retrofit and serialization.** Nothing in the app calls the data layer until milestone 5, so R8 removes all of it. Only Room's 4 invalidation-service classes stay, because Room's manifest declares the service, and an empty `missing_rules.txt` says nothing about the data layer yet. With a temporary caller in `MrdApplication`:
  - R8 traced Retrofit, OkHttp, kotlinx.serialization and Room, and `missing_rules.txt` stayed empty;
  - `dexdump` shows that R8 kept what Retrofit reads at run time: each API method's `@GET`, `@Headers` and `@Path` values, and its `Continuation<Response<ResponseBody>>` generic signature;
  - Room's rule kept the names `DiscoveryDatabase` and `DiscoveryDatabase_Impl`, which Room looks up by reflection;
  - the menu cache's generated serializer is kept. It's called directly, so it needs no reflection.

  The run-time proof on a device is milestone 5's release walk, the first with a caller.
- **The 304 test caught a design error.** With `Cache-Control: no-cache`, as spec §5.3 and the menus design said, OkHttp 5.3.2 skips its cache and sends no `If-None-Match`, so every refresh downloads the whole file. Its `CacheStrategy` returns no cached response when the request says `noCache` (`CacheStrategy.kt`, line 158), and `Cache`'s documentation recommends `max-age=0` for revalidation. With `max-age=0`, the second request carries the ETag, the 304 skips the database write, and the test passes. Task 12 corrects the spec.
- **Staleness (spec §5.6).** A refresh at each quarter hour of the week stores the true status as `is_open`. After *h* hours offline, the cached flag is wrong this often, among restaurants with hours:

  | Dataset | With hours | 1 h | 3 h | 6 h | 12 h |
  |---|---|---|---|---|---|
  | `restaurants.json` | 205 of 217 | 8.8% | 26.1% | 44.5% | 77.9% |
  | `restaurants-10k.json` | 9,481 of 9,997 | 8.8% | 26.1% | 44.5% | 77.4% |

  The derived status is right at every one of those moments. The restaurants without hours show as Unknown once the snapshot is 30 minutes old. The test takes about 2 seconds for both files.
- **Tests:** 44 new: 6 in `:core:model`, 2 in `:core:common` and 36 in `:core:data`. Every module together has 109 (51 in `:app` and `core`, 58 in `:tools:datagen`), and `ArchitectureTest`'s 7 rules stay green.
- **Gate:** `spotlessCheck :app:lintDebug testDebugUnitTest :app:assembleRelease` passed from a clean build in 50 seconds, with no compiler warnings, no lint issues, and the R8 check passing. A lint probe in `:core:data` showed up in `:app:lintDebug` once `:app` depended on the module (Task 10). Editing `restaurants.json` re-ran `:core:data`'s tests instead of leaving them `UP-TO-DATE`.
- **APK size** (release, R8): 979,364 bytes on `dev`, 1,047,540 after this plan (+68,176). Most of that is OkHttp's `PublicSuffixDatabase.list`, an asset R8 doesn't shrink; the rest is about 10 KB of DEX for Room's invalidation service. With a caller, the data layer adds about 278 KB more.
- **POM check:** every new artifact needs `kotlin-stdlib` 2.3.21 or lower. The highest are OkHttp and MockWebServer 5.3.2 (2.2.21) and room-compiler 2.8.4 (2.2.0). Retrofit 3.0.0 asks for OkHttp 4.12.0, and Gradle resolves it to 5.3.2.
- **Changes from the spec and the brief,** each proven in the spike and recorded in Task 12:
  - **`Cache-Control: max-age=0`**, not `no-cache` (above).
  - **`NetworkMonitor` lives in `:core:common`.** The implementation is in `:core:network`. Features may depend on `:core:common` but not on `:core:network` (§4.2), and they need connectivity to word their errors (§5.4).
  - **The build-config values live in `:core:data`,** not `:core:network`. The base URL and the dataset file are discovery's backend contract. A host adopting these modules keeps its own networking stack (§4.3), which wouldn't know our API's address.
  - **The snapshot swap replaces every restaurant** rather than deleting those missing from the snapshot. `NOT IN (:ids)` with 10,000 ids exceeds SQLite's 999-variable limit on Android 10 and lower. The end state is the same, still in one transaction, and favourites still stay.
  - **Freshness is computed in SQL from `sync_state` and `:now`,** not passed in as `:snapshotFresh`. A `PagingSource` factory can't suspend and runs where the list is collected, usually the main thread, so it can't read the database; and reading `sync_state` in the query makes Room re-run it when a sync lands.
  - **The payload is streamed** and each record validated as it's read, on the IO dispatcher, so a 10,000-restaurant payload never sits in memory as a JSON tree. §5.3 said it's mapped on `Dispatchers.Default` after the fetch.
  - **`rating_tenths`, not `rating`,** in the `restaurants` table, because `Rating` holds tenths: exact, and always shown with one decimal place.
  - **`:app` depends on `:core:data` now,** so the gate's `:app:lintDebug`, which only lints the app's dependencies, covers the new code.

```kotlin
package com.effekt3r.mrd.core.model

import java.time.DayOfWeek
import java.time.Duration
import java.time.Instant
import java.time.ZoneId

/** Restaurants keep Cape Town time. South Africa has no daylight saving, so every week is 10,080 minutes. */
val RESTAURANT_TIME_ZONE: ZoneId = ZoneId.of("Africa/Johannesburg")

const val MINUTES_PER_DAY = 24 * 60
const val MINUTES_PER_WEEK = 7 * MINUTES_PER_DAY

/** How long the server's `is_open` is trusted for a restaurant without hours (spec §5.6). */
val SNAPSHOT_TRUSTED_FOR: Duration = Duration.ofMinutes(30)

/** A minute of the week in Cape Town time: 0 is Monday 00:00 and 10,079 is Sunday 23:59. */
@JvmInline
value class WeekMinute(val value: Int) {
    init {
        require(value in 0 until MINUTES_PER_WEEK) { "A week minute is from 0 to 10,079, not $value" }
    }

    val day: DayOfWeek get() = DayOfWeek.of(value / MINUTES_PER_DAY + 1)

    /** Minutes after midnight: 1,320 is 22:00. */
    val minuteOfDay: Int get() = value % MINUTES_PER_DAY

    companion object {
        fun of(day: DayOfWeek, hour: Int, minute: Int = 0) = WeekMinute(
            day.ordinal * MINUTES_PER_DAY + hour * 60 + minute
        )

        fun at(instant: Instant): WeekMinute =
            instant.atZone(RESTAURANT_TIME_ZONE).let { of(it.dayOfWeek, it.hour, it.minute) }
    }
}

/**
 * One opening window as the API sends it: [opens] and [closes] are minutes after midnight on [day]. [closes] may be
 * 1,440 (24:00), or earlier than [opens] when the window ends the next day. A window can't open and close at once.
 */
data class DailyWindow(val day: DayOfWeek, val opens: Int, val closes: Int) {
    init {
        require(opens in 0 until MINUTES_PER_DAY && closes in 0..MINUTES_PER_DAY && opens != closes) {
            "Invalid window: $day $opens-$closes"
        }
    }
}

/** A half-open span of the week, [start, end) in week minutes. [end] is at most 10,080, the end of Sunday. */
data class WeekInterval(val start: Int, val end: Int) {
    init {
        require(start in 0 until end && end <= MINUTES_PER_WEEK) { "Invalid interval: $start-$end" }
    }

    operator fun contains(minute: WeekMinute) = minute.value >= start && minute.value < end
}

/**
 * A restaurant's weekly opening hours (spec §5.6): sorted intervals that neither overlap nor touch. A window that
 * runs past Sunday midnight is split, and its second part starts the week.
 */
data class OpeningHours(val intervals: List<WeekInterval>) {
    init {
        require(intervals.isNotEmpty()) { "Unknown hours are null, not empty" }
        require(intervals.zipWithNext().all { (a, b) -> a.end < b.start }) { "Unsorted or touching: $intervals" }
    }

    /** Open or Closed at [now], with the next change. */
    fun statusAt(now: WeekMinute): OpenStatus {
        val current = intervals.firstOrNull { now in it }
        if (current != null) return OpenStatus.Open(closesAt = closingOf(current))
        val next = intervals.firstOrNull { it.start > now.value } ?: intervals.first()
        return OpenStatus.Closed(opensAt = WeekMinute(next.start))
    }

    // An interval that runs to the end of Sunday carries on into the week's first interval when that starts at 00:00.
    private fun closingOf(interval: WeekInterval): WeekMinute? = when {
        interval.end < MINUTES_PER_WEEK -> WeekMinute(interval.end)
        interval.start == 0 -> null
        else -> WeekMinute(intervals.first().let { if (it.start == 0) it.end else 0 })
    }

    companion object {
        /**
         * The hours from the API's windows: a window past midnight ends the next day, one past Sunday midnight wraps to
         * the start of the week, and overlapping or touching windows merge. No windows means the hours are unknown.
         */
        fun from(windows: List<DailyWindow>): OpeningHours? {
            val spans = windows.flatMap { window ->
                val dayStart = window.day.ordinal * MINUTES_PER_DAY
                val start = dayStart + window.opens
                val end = dayStart + window.closes + if (window.closes > window.opens) 0 else MINUTES_PER_DAY
                if (end <= MINUTES_PER_WEEK) {
                    listOf(WeekInterval(start, end))
                } else {
                    listOf(WeekInterval(start, MINUTES_PER_WEEK), WeekInterval(0, end - MINUTES_PER_WEEK))
                }
            }
            val merged = spans.sortedBy { it.start }.fold(emptyList<WeekInterval>()) { acc, span ->
                val last = acc.lastOrNull()
                if (last != null && span.start <= last.end) {
                    acc.dropLast(1) + WeekInterval(last.start, maxOf(last.end, span.end))
                } else {
                    acc + span
                }
            }
            return merged.takeIf { it.isNotEmpty() }?.let(::OpeningHours)
        }
    }
}

/** Whether a restaurant is open, and when that next changes. */
sealed interface OpenStatus {
    /** [closesAt] is null when it never closes (open around the clock) or the hours are unknown. */
    data class Open(val closesAt: WeekMinute?) : OpenStatus

    /** [opensAt] is null when the hours are unknown. */
    data class Closed(val opensAt: WeekMinute?) : OpenStatus

    /** No hours, and the server's snapshot is too old to trust. */
    data object Unknown : OpenStatus
}

/**
 * A restaurant's status at [now] (spec §5.6). Known hours decide. Without them, the server's [openSnapshot] counts while
 * the snapshot, taken at [snapshotAt], is fresh; after that the app doesn't guess.
 */
fun openStatus(hours: OpeningHours?, openSnapshot: Boolean?, snapshotAt: Instant?, now: Instant): OpenStatus = when {
    hours != null -> hours.statusAt(WeekMinute.at(now))
    openSnapshot == null || !isSnapshotFresh(snapshotAt, now) -> OpenStatus.Unknown
    openSnapshot -> OpenStatus.Open(closesAt = null)
    else -> OpenStatus.Closed(opensAt = null)
}

/** Whether a snapshot is less than 30 minutes old. One from the future (the clock was set back) isn't trusted. */
fun isSnapshotFresh(snapshotAt: Instant?, now: Instant): Boolean =
    snapshotAt != null && !now.isBefore(snapshotAt) && Duration.between(snapshotAt, now) < SNAPSHOT_TRUSTED_FOR
```

package com.effekt3r.mrd.core.common

import java.time.Clock
import java.time.Instant
import javax.inject.Inject
import kotlinx.coroutines.delay
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.flow

/** The current time, now and then at the start of every minute, so open statuses stay current (spec §5.6). */
interface MinuteTicker {
    /** A cold flow: it ticks only while it's collected. */
    fun ticks(): Flow<Instant>
}

class ClockMinuteTicker @Inject constructor(private val clock: Clock) : MinuteTicker {
    override fun ticks(): Flow<Instant> = flow {
        while (true) {
            val now = clock.instant()
            emit(now)
            delay(MILLIS_PER_MINUTE - Math.floorMod(now.toEpochMilli(), MILLIS_PER_MINUTE))
        }
    }

    private companion object {
        const val MILLIS_PER_MINUTE = 60_000L
    }
}

package com.effekt3r.mrd.core.network

import android.content.Context
import android.net.ConnectivityManager
import android.net.Network
import android.net.NetworkCapabilities
import com.effekt3r.mrd.core.common.NetworkMonitor
import dagger.hilt.android.qualifiers.ApplicationContext
import javax.inject.Inject
import kotlinx.coroutines.channels.awaitClose
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.callbackFlow
import kotlinx.coroutines.flow.conflate
import kotlinx.coroutines.flow.distinctUntilChanged

/** Validated internet on the default network, from the platform's callback, registered only while collected. */
internal class ConnectivityManagerNetworkMonitor @Inject constructor(@ApplicationContext context: Context) :
    NetworkMonitor {
    private val manager: ConnectivityManager? = context.getSystemService(ConnectivityManager::class.java)

    override val isOnline: Flow<Boolean> = callbackFlow {
        val manager = manager
        if (manager == null) {
            send(false)
            close()
            return@callbackFlow
        }
        val callback = object : ConnectivityManager.NetworkCallback() {
            override fun onCapabilitiesChanged(network: Network, capabilities: NetworkCapabilities) {
                trySend(capabilities.hasValidatedInternet())
            }

            override fun onLost(network: Network) {
                trySend(false)
            }
        }
        // The callback reports changes only, so start from the current state.
        trySend(manager.getNetworkCapabilities(manager.activeNetwork)?.hasValidatedInternet() == true)
        manager.registerDefaultNetworkCallback(callback)
        awaitClose { manager.unregisterNetworkCallback(callback) }
    }.distinctUntilChanged().conflate()

    private fun NetworkCapabilities.hasValidatedInternet() =
        hasCapability(NetworkCapabilities.NET_CAPABILITY_INTERNET) &&
            hasCapability(NetworkCapabilities.NET_CAPABILITY_VALIDATED)
}

import kotlinx.serialization.SerializationException
import kotlinx.serialization.builtins.ListSerializer
import kotlinx.serialization.descriptors.SerialDescriptor
import kotlinx.serialization.descriptors.buildClassSerialDescriptor
import kotlinx.serialization.encoding.CompositeDecoder
import kotlinx.serialization.encoding.Decoder
import kotlinx.serialization.encoding.decodeStructure
import kotlinx.serialization.json.JsonElement
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.JsonPrimitive

/** One restaurant that passed spec §5.1's validation, in the server's order. */
internal data class ParsedRestaurant(
    val id: String,
    val name: String,
    val cuisines: List<String>,
    val rating: Rating?,
    val deliveryFeeCents: Long?,
    val etaMinutes: Int?,
    val isOpen: Boolean?,
    val imageUrl: String?,
    val hours: OpeningHours?
)

/** How many records the payload held, and the ones that passed. All of them failing is bad data (spec §5.3). */
internal data class ParsedPayload(val recordCount: Int, val restaurants: List<ParsedRestaurant>)

/**
 * Reads `{"restaurants": [...]}` one record at a time and validates each as soon as it's read, so a 10,000-restaurant
 * payload never sits in memory as a JSON tree. Malformed JSON, or a payload without the array, throws
 * [SerializationException].
 */
internal object RestaurantsPayloadReader : DeserializationStrategy<ParsedPayload> {
    private val records = ListSerializer(JsonElement.serializer())

    override val descriptor: SerialDescriptor = buildClassSerialDescriptor("RestaurantsPayload") {
        element("restaurants", records.descriptor)
    }

    override fun deserialize(decoder: Decoder): ParsedPayload = decoder.decodeStructure(descriptor) {
        var payload: ParsedPayload? = null
        while (true) {
            when (val index = decodeElementIndex(descriptor)) {
                0 -> payload = decodeSerializableElement(descriptor, 0, RecordsReader)
                CompositeDecoder.DECODE_DONE -> break
                else -> throw SerializationException("Unexpected element $index")
            }
        }
        payload ?: throw SerializationException("The payload has no restaurants array")
    }

    private object RecordsReader : DeserializationStrategy<ParsedPayload> {
        override val descriptor: SerialDescriptor = records.descriptor

        override fun deserialize(decoder: Decoder): ParsedPayload = decoder.decodeStructure(descriptor) {
            var count = 0
            val ids = HashSet<String>()
            val restaurants = ArrayList<ParsedRestaurant>()
            while (true) {
                val index = decodeElementIndex(descriptor)
                if (index == CompositeDecoder.DECODE_DONE) break
                count++
                // The id is the primary key, so a repeated id keeps the first record (spec §5.5).
                RestaurantValidator.validate(decodeSerializableElement(descriptor, index, JsonElement.serializer()))
                    ?.takeIf { ids.add(it.id) }
                    ?.let(restaurants::add)
            }
            ParsedPayload(count, restaurants)
        }
    }
}

/** Spec §5.1's rules for one record: no usable id or name drops it, and any other bad value reads as missing. */
internal object RestaurantValidator {
    private val days = DayOfWeek.entries.associateBy { it.name }
    private val time = Regex("""([01]\d|2[0-4]):([0-5]\d)""")

    fun validate(record: JsonElement): ParsedRestaurant? {
        val fields = record as? JsonObject ?: return null
        return ParsedRestaurant(
            id = fields.text("id") ?: return null,
            name = fields.text("name") ?: return null,
            cuisines = fields.array("cuisines").mapNotNull { it.textValue() }.distinct(),
            rating = fields.double("rating")?.takeIf { it in 0.0..5.0 }?.let { Rating((it * 10).roundToInt()) },
            deliveryFeeCents = fields.long("delivery_fee_cents")?.takeIf { it >= 0 },
            etaMinutes = fields.long("eta_minutes")?.takeIf { it in 1..Int.MAX_VALUE }?.toInt(),
            isOpen = fields.boolean("is_open"),
            imageUrl = fields.httpsUrl("image_url"),
            hours = OpeningHours.from(fields.array("opening_hours").mapNotNull(::window))
        )
    }

    // A cuisine: a string that isn't blank. Blank entries are removed, and so are repeats (by distinct()).
    private fun JsonElement.textValue(): String? =
        (this as? JsonPrimitive)?.takeIf { it.isString }?.content?.trim()?.takeIf { it.isNotEmpty() }

    // An entry with an unknown day, a time that isn't HH:mm, or the same opening and closing time is dropped.
    private fun window(entry: JsonElement): DailyWindow? {
        val fields = entry as? JsonObject ?: return null
        val day = fields.string("day")?.let(days::get) ?: return null
        val opens = fields.string("opens")?.let(::minutes)?.takeIf { it < MINUTES_PER_DAY } ?: return null
        val closes = fields.string("closes")?.let(::minutes) ?: return null
        return if (opens == closes) null else DailyWindow(day, opens, closes)
    }

    /** "HH:mm" as minutes after midnight, where "24:00" is 1,440. "25:00" or "24:30" are null. */
    private fun minutes(text: String): Int? = time.matchEntire(text)
        ?.destructured
        ?.let { (hours, minutes) -> hours.toInt() * 60 + minutes.toInt() }
        ?.takeIf { it <= MINUTES_PER_DAY }
}

import androidx.paging.PagingSource
import androidx.room.ColumnInfo

// Open now and the list's status in SQL (spec §5.6), by the same rules as openStatus() in :core:model, so paging and
// the count stay correct at 10,000 rows. `c` is the interval containing :weekMinute, if any; intervals never overlap.
private const val FROM_RESTAURANTS = """
    FROM restaurants r
    LEFT JOIN opening_intervals c
        ON c.restaurant_id = r.id AND c.start_minute <= :weekMinute AND c.end_minute > :weekMinute
"""

// The snapshot is from 0 to 30 minutes old (1,800,000 ms, exclusive). With no sync_state row it's NULL: not fresh.
private const val SNAPSHOT_FRESH = """
    (:now - (SELECT s.last_synced_at FROM sync_state s WHERE s.id = 0)) BETWEEN 0 AND 1799999
"""

private const val STATUS = """
    CASE
        WHEN r.has_hours THEN CASE WHEN c.restaurant_id IS NULL THEN 'CLOSED' ELSE 'OPEN' END
        WHEN r.is_open_snapshot IS NOT NULL AND $SNAPSHOT_FRESH
            THEN CASE WHEN r.is_open_snapshot THEN 'OPEN' ELSE 'CLOSED' END
        ELSE 'UNKNOWN'
    END
"""

// The week minute of the next change. Closed: the next interval's start, else the week's first. Open: the interval's
// end; one that runs to the end of Sunday carries on into an interval starting Monday 00:00. NULL: it never closes.
private const val NEXT_CHANGE = """
    CASE
        WHEN NOT r.has_hours THEN NULL
        WHEN c.restaurant_id IS NULL THEN COALESCE(
            (SELECT MIN(n.start_minute) FROM opening_intervals n
                WHERE n.restaurant_id = r.id AND n.start_minute > :weekMinute),
            (SELECT MIN(n.start_minute) FROM opening_intervals n WHERE n.restaurant_id = r.id))
        WHEN c.end_minute < 10080 THEN c.end_minute
        WHEN c.start_minute = 0 THEN NULL
        ELSE COALESCE(
            (SELECT w.end_minute FROM opening_intervals w WHERE w.restaurant_id = r.id AND w.start_minute = 0), 0)
    END
"""

// :query is already a search key with LIKE's wildcards escaped (likePattern).
private const val MATCHES = """
    WHERE r.name_search LIKE '%' || :query || '%' ESCAPE '\'
        AND (NOT :openNow OR $STATUS = 'OPEN')
"""

/** One restaurant in the list, with its status at the query's week minute: OPEN, CLOSED or UNKNOWN. */
internal data class RestaurantRow(
    val id: String,
    val name: String,
    val cuisines: List<String>,
    @ColumnInfo(name = "rating_tenths") val ratingTenths: Int?,
    @ColumnInfo(name = "delivery_fee_cents") val deliveryFeeCents: Long?,
    @ColumnInfo(name = "eta_minutes") val etaMinutes: Int?,
    @ColumnInfo(name = "image_url") val imageUrl: String?,
    @ColumnInfo(name = "is_favourite") val isFavourite: Boolean,
    val status: String,
    @ColumnInfo(name = "next_change") val nextChange: Int?
)

internal data class RestaurantWithHours(
    @Embedded val restaurant: RestaurantEntity,
    @ColumnInfo(name = "is_favourite") val isFavourite: Boolean,
    @Relation(parentColumn = "id", entityColumn = "restaurant_id") val intervals: List<OpeningIntervalEntity>
)

@Dao
internal interface RestaurantDao {
    @Query(
        """
        SELECT r.id, r.name, r.cuisines, r.rating_tenths, r.delivery_fee_cents, r.eta_minutes, r.image_url,
            EXISTS (SELECT 1 FROM favourites f WHERE f.restaurant_id = r.id) AS is_favourite,
            $STATUS AS status, $NEXT_CHANGE AS next_change
        $FROM_RESTAURANTS $MATCHES
        ORDER BY r.position
        """
    )
    fun restaurants(query: String, openNow: Boolean, weekMinute: Int, now: Long): PagingSource<Int, RestaurantRow>

    @Query("SELECT COUNT(*) $FROM_RESTAURANTS $MATCHES")
    fun count(query: String, openNow: Boolean, weekMinute: Int, now: Long): Flow<Int>

    @Transaction
    @Query(
        """
        SELECT r.*, EXISTS (SELECT 1 FROM favourites f WHERE f.restaurant_id = r.id) AS is_favourite
        FROM restaurants r WHERE r.id = :id
        """
    )
    fun restaurant(id: String): Flow<RestaurantWithHours?>

    @Query("SELECT last_synced_at FROM sync_state WHERE id = 0")
    fun lastSyncedAt(): Flow<Long?>

    @Query("SELECT EXISTS (SELECT 1 FROM restaurants)")
    suspend fun hasRestaurants(): Boolean

    @Upsert
    suspend fun setSyncState(state: SyncStateEntity)

    @Query("DELETE FROM restaurants")
    suspend fun deleteRestaurants()

    @Insert
    suspend fun insertRestaurants(restaurants: List<RestaurantEntity>)

    @Insert
    suspend fun insertIntervals(intervals: List<OpeningIntervalEntity>)

    /**
     * Swaps in a new snapshot in one transaction (spec §5.3): readers see the old one until it commits. Deleting every
     * restaurant (their intervals cascade) rather than those missing from the snapshot avoids `NOT IN (:ids)`, which
     * would exceed SQLite's 999-variable limit on Android 10 and lower. Favourites have no foreign key, so they stay.
     */
    @Transaction
    suspend fun replaceSnapshot(
        restaurants: List<RestaurantEntity>,
        intervals: List<OpeningIntervalEntity>,
        syncedAt: Long
    ) {
        deleteRestaurants()
        insertRestaurants(restaurants)
        insertIntervals(intervals)
        setSyncState(SyncStateEntity(lastSyncedAt = syncedAt))
    }

    @Query("SELECT EXISTS (SELECT 1 FROM favourites WHERE restaurant_id = :id)")
    suspend fun isFavourite(id: String): Boolean

    @Insert
    suspend fun insertFavourite(favourite: FavouriteEntity)

    @Query("DELETE FROM favourites WHERE restaurant_id = :id")
    suspend fun deleteFavourite(id: String)

    @Transaction
    suspend fun toggleFavourite(id: String, now: Long) {
        if (isFavourite(id)) deleteFavourite(id) else insertFavourite(FavouriteEntity(id, now))
    }
}

/** Whether a refresh is running, and how the last one failed (null: it worked, or none has run yet). */
internal data class RefreshState(val isRefreshing: Boolean = false, val lastError: SyncError? = null)

/** Fetches the restaurant snapshot into Room (spec §5.3). */
@Singleton
internal class RestaurantSync @Inject constructor(
    private val api: DiscoveryApi,
    private val dao: RestaurantDao,
    private val json: Json,
    private val clock: Clock,
    @IoDispatcher private val ioDispatcher: CoroutineDispatcher,
    @ApplicationScope private val scope: CoroutineScope
) {
    private val mutableState = MutableStateFlow(RefreshState())
    val state: StateFlow<RefreshState> = mutableState.asStateFlow()

    private val lock = Mutex()
    private var running: Deferred<Unit>? = null

    /**
     * Fetches a new snapshot. A call while a refresh runs joins it, so overlapping refreshes make one request. The
     * refresh runs in the application scope, so a caller that goes away doesn't cancel it for the others.
     */
    suspend fun refresh() {
        val refresh = lock.withLock {
            running?.takeIf { it.isActive } ?: scope.async { run() }.also { running = it }
        }
        refresh.await()
    }

    /** Refreshes when there's no snapshot yet, or it's at least 5 minutes old. */
    suspend fun refreshIfStale() {
        val age = dao.lastSyncedAt().first()?.let { clock.millis() - it }
        if (age == null || age !in 0 until STALE_AFTER_MILLIS) refresh()
    }

    private suspend fun run() {
        mutableState.update { it.copy(isRefreshing = true) }
        // Every failure becomes a SyncError here, exactly once (spec §5.4).
        val error = try {
            download()
        } catch (e: IOException) {
            SyncError.Network
        } catch (e: IllegalArgumentException) {
            SyncError.BadData // malformed JSON: SerializationException is an IllegalArgumentException
        }
        mutableState.value = RefreshState(isRefreshing = false, lastError = error)
    }

    // decodeFromStream streams the body; it has been experimental since 1.3 but is stable in practice.
    @OptIn(ExperimentalSerializationApi::class)
    /** Null when the snapshot was stored or confirmed unchanged; otherwise why it wasn't. */
    private suspend fun download(): SyncError? {
        val response = api.restaurants()
        if (!response.isSuccessful) {
            response.errorBody()?.close()
            return SyncError.Server(response.code())
        }
        val body = response.body() ?: return SyncError.BadData
        return body.use {
            val now = clock.millis()
            // OkHttp answers a 304 with its cached copy; the network response keeps the real code.
            if (response.raw().networkResponse?.code == HTTP_NOT_MODIFIED && dao.hasRestaurants()) {
                dao.setSyncState(SyncStateEntity(lastSyncedAt = now))
                return@use null
            }
            val payload = withContext(ioDispatcher) { json.decodeFromStream(RestaurantsPayloadReader, it.byteStream()) }
            // Records that all failed validation are bad data, and never replace the snapshot.
            if (payload.recordCount > 0 && payload.restaurants.isEmpty()) return@use SyncError.BadData
            dao.replaceSnapshot(
                restaurants = payload.restaurants.mapIndexed { position, restaurant -> restaurant.toEntity(position) },
                intervals = payload.restaurants.flatMap { it.intervalEntities() },
                syncedAt = now
            )
            null
        }
    }

    private companion object {
        const val STALE_AFTER_MILLIS = 5 * 60 * 1000L
    }
}

        // Each tick invalidates the PagingSource instead of building a new Pager, so Paging's refresh key keeps the
        // scroll position when a status flips (spec §5.6). The first tick is now, which the first source already used.
        launch { ticker.ticks().drop(1).collect { sources.invalidate() } }
        Pager(PagingConfig(pageSize = PAGE_SIZE), pagingSourceFactory = sources).flow
            .collect { send(it.map(RestaurantRow::toModel)) }
    }

    @OptIn(ExperimentalCoroutinesApi::class)
    override fun count(query: String, openNow: Boolean): Flow<Int> {
        val pattern = likePattern(query)
        return ticker.ticks()
            .flatMapLatest { now -> dao.count(pattern, openNow, WeekMinute.at(now).value, now.toEpochMilli()) }
            .distinctUntilChanged()
    }

    override fun restaurant(id: RestaurantId): Flow<Restaurant?> =
        combine(dao.restaurant(id.value), dao.lastSyncedAt(), ticker.ticks()) { row, syncedAt, now ->
            row?.toModel(snapshotAt = syncedAt?.let(Instant::ofEpochMilli), now = now)
        }.distinctUntilChanged()

    override val syncStatus: Flow<SyncStatus> = channelFlow {
        launch {
            // Only a change back to online counts, never the first value.
            networkMonitor.isOnline.distinctUntilChanged().drop(1).filter { it }.collect {
                if (sync.state.value.lastError != null) sync.refresh()
            }
        }
        combine(dao.lastSyncedAt(), sync.state) { syncedAt, state ->
            SyncStatus(syncedAt?.let(Instant::ofEpochMilli), state.isRefreshing, state.lastError)
        }.collect { send(it) }
    }

    override suspend fun refresh() = sync.refresh()

    override suspend fun refreshIfStale() = sync.refreshIfStale()

    override suspend fun toggleFavourite(id: RestaurantId) = dao.toggleFavourite(id.value, clock.millis())

    private companion object {
        const val PAGE_SIZE = 30
    }
}

package com.effekt3r.mrd.core.data.network

import com.effekt3r.mrd.core.model.Menu
import com.effekt3r.mrd.core.model.MenuCategory
import com.effekt3r.mrd.core.model.MenuItem
import com.effekt3r.mrd.core.model.MenuOption
import com.effekt3r.mrd.core.model.Money
import kotlinx.serialization.json.JsonArray
import kotlinx.serialization.json.JsonElement
import kotlinx.serialization.json.JsonObject

/** Spec §5.9's rules for a menu. Within a menu, the first of two equal ids wins. */
internal object MenuParser {

    /** The validated menu, or null for bad data: another restaurant's menu, or items that all failed validation. */
    fun parse(payload: JsonElement, restaurantId: String): Menu? {
        val fields = payload as? JsonObject ?: return null
        if (fields.string("restaurant_id") != restaurantId) return null
        val rawCategories = fields["categories"] as? JsonArray ?: return null
        val categoryIds = HashSet<String>()
        val itemIds = HashSet<String>()
        val categories = rawCategories.mapNotNull { element ->
            val category = element as? JsonObject ?: return@mapNotNull null
            val id = category.text("id") ?: return@mapNotNull null
            val name = category.text("name") ?: return@mapNotNull null
            if (!categoryIds.add(id)) return@mapNotNull null
            // A category left with no valid items is hidden.
            category.array("items").mapNotNull(::item).filter { itemIds.add(it.id) }
                .takeIf { it.isNotEmpty() }
                ?.let { MenuCategory(id, name, it) }
        }
        val hadItems = rawCategories.any { (it as? JsonObject)?.array("items")?.isNotEmpty() == true }
        return if (hadItems && categories.isEmpty()) null else Menu(categories)
    }

    // An item without an id, a name or a price of 0 or more can't be ordered, so it's dropped.
    private fun item(element: JsonElement): MenuItem? {
        val fields = element as? JsonObject ?: return null
        val optionIds = HashSet<String>()
        return MenuItem(
            id = fields.text("id") ?: return null,
            name = fields.text("name") ?: return null,
            price = fields.money("price_cents") ?: return null,
            isAvailable = fields.boolean("available") ?: true,
            description = fields.text("description"),
            imageUrl = fields.httpsUrl("image_url"),
            options = fields.array("options").mapNotNull(::option).filter { optionIds.add(it.id) }
        )
    }

    private fun option(element: JsonElement): MenuOption? {
        val fields = element as? JsonObject ?: return null
        return MenuOption(
            id = fields.text("id") ?: return null,
            name = fields.text("name") ?: return null,
            price = fields.money("price_cents") ?: return null
        )
    }

    private fun JsonObject.money(key: String): Money? = long(key)?.takeIf { it >= 0 }?.let(::Money)
}

    @IoDispatcher private val ioDispatcher: CoroutineDispatcher

    // flowOn: the response body is read where the flow runs, which must not be the main thread.
    override fun menu(id: RestaurantId): Flow<MenuState> = flow {
        val cached = dao.menu(id.value)?.let {
            MenuState.Content(
                json.decodeFromString(CachedMenu.serializer(), it.menuJson).toModel(),
                Instant.ofEpochMilli(it.fetchedAt)

        emit(cached ?: MenuState.Loading)
        emit(fetch(id.value, cached))
    }.flowOn(ioDispatcher)

    // The same client, ETag revalidation and error mapping as the list (spec §5.9), plus NotAvailable for a 404.
    private suspend fun fetch(restaurantId: String, cached: MenuState.Content?): MenuState {
        val menu = try {
            val response = api.menu(restaurantId)
            if (!response.isSuccessful) {
                response.errorBody()?.close()
                if (response.code() == HTTP_NOT_FOUND) return notAvailable(restaurantId)
                return MenuState.Error(SyncError.Server(response.code()), cached)
            }
            response.body()?.use { MenuParser.parse(json.parseToJsonElement(it.string()), restaurantId) }
        } catch (e: IOException) {
            return MenuState.Error(SyncError.Network, cached)
        } catch (e: IllegalArgumentException) {
            null // malformed JSON
        }
        return when {
            menu == null -> MenuState.Error(SyncError.BadData, cached)
            menu.categories.isEmpty() -> notAvailable(restaurantId)
            else -> {
                val fetchedAt = clock.instant()
                val menuJson = json.encodeToString(CachedMenu.serializer(), menu.toCached())
                dao.upsert(MenuEntity(restaurantId, menuJson, fetchedAt.toEpochMilli()))
                MenuState.Content(menu, fetchedAt)
            }
        }
    }

    // A 404 or an empty menu: "hasn't shared a menu yet", and no older menu is kept for it.
    private suspend fun notAvailable(restaurantId: String): MenuState {
        dao.delete(restaurantId)
        return MenuState.NotAvailable
    }
}

import com.effekt3r.mrd.core.data.network.RestaurantsPayloadReader

import org.junit.Test

/**
 * Spec §5.6's measurement for SOLUTION.md: how many open statuses a cached `is_open` gets wrong after hours offline.
 * A refresh at each quarter hour of the week stores the true status as `is_open`; after 1, 3, 6 and 12 hours offline,
 * the flag is wrong wherever the hours say the status has changed since. Only restaurants with hours count: for the
 * others there's no truth to compare, and the app shows them as Unknown once the snapshot is 30 minutes old. The
 * status the app derives from the hours is right at every one of those moments, because it's computed for that moment.
 */
class StalenessMeasurementTest {

    @Test
    fun cachedIsOpenOver220Restaurants() =
        assertEquals("205 with hours; wrong after 1h 8.8%, 3h 26.1%, 6h 44.5%, 12h 77.9%", measure("restaurants.json"))

    @Test
    fun cachedIsOpenOver10000Restaurants() = assertEquals(

        measure("restaurants-10k.json")
    )

    @OptIn(ExperimentalSerializationApi::class)
    private fun measure(file: String): String {
        val payload = File("../../mock-api/v1/$file").inputStream().use {
            testJson.decodeFromStream(RestaurantsPayloadReader, it)
        }
        val hours = payload.restaurants.mapNotNull { it.hours }
        // Whether each restaurant is open at each minute of the week, worked out once.
        val open = hours.map { it.openMinutes() }
        val refreshes = 0 until MINUTES_PER_WEEK step 15
        val results = listOf(1, 3, 6, 12).joinToString { offline ->
            val wrong = open.sumOf { minutes ->
                refreshes.count { at -> minutes[at] != minutes[(at + offline * 60) % MINUTES_PER_WEEK] }
            }
            "${offline}h ${percent(wrong, open.size * refreshes.count())}"
        }
        return "${hours.size} with hours; wrong after $results"
    }

    private fun OpeningHours.openMinutes() = List(MINUTES_PER_WEEK) { statusAt(WeekMinute(it)) is OpenStatus.Open }

    // One decimal place, rounded half up, without floating point.
    private fun percent(part: Int, whole: Int): String {
        val tenths = (part * 1000L + whole / 2) / whole
        return "${tenths / 10}.${tenths % 10}%"
    }
}
